# 冻结推理系统简化检验 v1

本包属于阶段 3 准备，尚未获批执行。唯一 attempt 为 `stage3-runtime-necessity-v1-once`。本轮准备的环境步、模型前向、reset、训练更新和正式 attempt 均为 0。授权文件模板为 `approved=false`；正式入口在任何 worker、模型加载或 SQLite 创建之前核验独立授权和完整冻结哈希。

## 依据与可改变的决策

阶段 2 已完整完成 1600 个独立父场景 × 3 个外生重复 × M/R，共 9600 个 episode。在历史原生 M10 25-action/W1、seed-1101、固定偏好下，模型 M 相对强公开信息规则 R 的效用差为 0.0660184，父场景 bootstrap 95% CI [0.0623413, 0.0697421]，超过原实用阈值 0.01（原生效用单位，不是百分点）；任务护栏和成本门通过。模型平均控制 CPU 为 9.1052176 ms，规则为 15.3280931 ms。更高任务收益同时伴随更多能耗，不能只报告任务成功率。

这证明组合系统在冻结范围内值得继续审查，不证明世界模型的独立贡献。P_train 曾在 WD 世界模型训练基础上继续 8192 环境步、63 次策略更新。历史 WB/WD 虽存在同初始条件和训练配方的对照，但 WB 与当前 P_train 训练量不匹配；WB/WD 本身也耦合世界模型损失、共享编码器和事件辅助。不能把历史 WB 直接作为本次的“同训练预算无世界模型”对照。

本实验的问题：冻结当前策略，移除全部在线 world 计算和 candidate_actor 加性输出，能否在保留实用收益与任务护栏的同时，至少降低 20% 控制 CPU 成本？成功支持简化当前推理系统；失败只否定直接移除，不能证明 world 预测或其训练是独立收益来源。

## 唯一干预及比较边界

- M：原阶段 2 完整系统，9600 条中 4800 条 M 结果原样复用。
- R：原阶段 2 强规则，4800 条结果原样复用。
- N：当前同一 P_train checkpoint，保留公开历史编码、policy hidden、偏好读出、公开 ACK 执行状态 guard 和原生动作路径；不计算世界模型，不推进 world hidden，不使用 candidate_actor。N **训练时使用过世界模型**，不能命名为“不使用世界模型训练的策略”。

不改变环境、奖励、偏好 (0.8,0.2)、强规则、场景、任务集合、外生键或统计口径。保留未使用的 world 权重与对象，以核验完整 checkpoint 身份；不声称模型文件体积或加载内存已经缩减。关闭在线分支后输入分布/共适应可能改变，这构成负结果的解释限制。

唯一模型 checkpoint SHA-256：`bf10d2685a4a3e9da036689f5028b022330e86e922e09c95a7dd0a929df9bb1a`。Python 3.14.4、torch 2.13.0+cpu、intra=4/inter=1，本地 Windows CPU。原生源码、配置、checkpoint、公开控制器和旧结果均由 execution-manifest.json 逐文件绑定。

## 固定 A → B → C

**A：数值与成本门。** 复用已公开的 25 个 M 决策输入，3 个独立 worker：full M、原生 actor 末端 candidate 输出置零参考实现、优化 N 实现。每个 worker 固定 21 批，每批 25 次；逐批轮换正向/反向顺序，暂停 worker 仍计驻留 RSS。reference 与 N 的 guard、动作、logits、概率及 policy hidden 必须逐位相同，每批自身必须复现；full M 需复现历史动作、guard 和选中 world hidden。使用同一选择与计时框架，tensor 哈希、磁盘、SQLite 在控制计时之外；完整进程 CPU 则全部计入。

21 批全部纳入主 CPU 比率，首批和后 20 批另行展示，不筛选快段。A 是固定轨迹的实现检验，不是反事实任务结果。N 的公开记忆按自己的提议更新；full 与 N 可有不同动作，不能把 A 的动作变化当收益。N 的平均控制 CPU ≤10 ms、wall p95 ≤50 ms 才过绝对成本门；20% 节省是最终实用决策条件，不据此筛选场景。

**B：原生 episode 接口门。** 由冻结原生生成器生成 2 个技术父场景，base_seed=925310000，W1/mixed；正常 reset，固定新技术外生键，不从模型结果选场景。最多 36 环境步、2 reset。检查公开动作、guard、计数、原生终止、独立奖励复算和完整计费；没有胜负或成功率通过条件。不得与正式父场景重叠。B 通过自动进入 C。

**C：完整固定矩阵。** 复用全部 1600 个阶段 2 父场景，顺序 eval-0000..1599，每父 repeat-0..2，N 共 4800 个 episode。sample-manifest.json 明确每个 parent/repeat/arm、tape hash、外生键及原 M/R reset 公开哈希。每个 episode 正常重新初始化环境、公开记忆与 policy hidden；不从快照中挑选前缀。原 horizon=18、interval=1，因此最多 86400 环境步。M/R 不重跑，N 每个 reset 必须与原 M/R 同键公开初态相同。

这些父场景在阶段 2 结果之后已成为开发场景，本轮不是全新盲测。纳入全部父场景，不能按差异、模型表现、任务成功或时间删除/替换项；model seed 和重复不增加独立父场景数。两臂轨迹分叉后只在 episode/parent 层面配对，不能逐步强配对。

## 标签、统计与去留标准

逐步原生 reward 独立按 float32 复算：任务分量 (新增完成−新增过期)/6，能耗分量 −新增能耗/36；效用固定为 Σ 0.99^k × (0.4*r_task+0.2*r_energy)。物理按时到达、主机按时确认和能耗独立报告，不修改 scalar 奖励或 deadline。

完整矩阵后分析；中途仅输出进度和资源，不看部分主效应。先对每父场景的 3 次重复平均，之后 1600 父场景配对 bootstrap，10000 次，seed=20260925，报告双侧 95% 百分位区间。三个同时验收的研究条件及成本条件全部固定：

1. N−M 效用 CI 下界 **>−0.01**；这是本轮明确的非劣界，等于阶段 2 最小实用差，不称效用完全相等。
2. N−R 效用 CI 下界 **>+0.01**，保留相对强规则的实用增量。
3. N−M 物理按时率和主机按时率父场景宏平均差均 ≥0；同时给出各自 CI。该样本护栏不等于已证明总体安全非劣。
4. N 平均控制 CPU ≤10 ms，wall p95 ≤50 ms；完整 RSS ≤4 GiB。
5. N/full M 的 A 全 21 批 CPU 总量比 ≤0.8；C 中 N 每决策平均 CPU/历史 M 全矩阵平均 CPU ≤0.8。两项都满足才接受至少 20% 节省。历史跨次计时受系统状态影响；A 的同机交替测量提供辅助控制，不升级为普遍硬件加速结论。

全部满足：支持冻结在线 world 移除，下一步只准备简化候选的进一步验证。
若 N−M CI 上界 <−0.01，或样本任务护栏不通过：不支持直接移除；不宣称 world 独立价值，不自动补训。
若任务非劣、规则增量与护栏通过而成本不通过：保留收益的证据成立，但简化的成本收益不获验收。
其他情况：证据不确定，停止，不补样、不换偏好、不换种子、不调参。
