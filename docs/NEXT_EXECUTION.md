## 目标

检验GPPO＋世界模型＋偏好条件策略是否值得优先于代表性传统方法和标准强化学习，而不仅是已测试的单个搜索规划器。保留该主方向，组件是否必要由后续证据决定。

## 准备工作

1. 盘点最近距离/最早截止贪心、滚动匈牙利、已有5000节点搜索规则、标准PPO、从头训练无world的GPPO及完整系统。代码存在不等于已有同协议结果。
2. 冻结相同公开信息、历史记忆权限、ACK/未确认命令过滤、25-action单动作提交及原生标签。PPO具体架构、滚动匹配评分与序列化必须先确定。
3. 分开历史开发补充与新的独立parent确认性比较；不把已观察的阶段2或800-parent诊断集称为新盲测。不按模型表现筛场景。
4. 预定主比较、多重比较处理、训练seed及parent不确定性、样本量。对齐完整训练谱系、环境步和调参额度，另报计算成本；不能把N当成标准PPO。
5. 提交一次明确资源申请，涵盖实现技术门、训练、推理、环境执行、reset/加载、wall/CPU/RSS和制品；当前文档不设自动可消费预算或交付日期。
