## 1. 研究问题与已有证据边界

主候选保留 GPPO＋世界模型＋偏好条件策略。要回答：在同等决策时信息下，相比低成本规则、经典分配优化和标准强化学习，实际任务收益能否抵偿复杂性与成本。

已核验的阶段2主对照是公开历史有限搜索规划器 R，每决策最多展开5000节点。“强规则”仅指这个具体实现，不代表所有经典算法的最优水平。历史比较使用原生 M10、W1、25动作、模型 seed-1101；结果不迁移成有限 token 通信环境、跨任务家族或多训练种子的结论。

阶段2 M/R 的物理按时率约为86.92%/77.47%，主机按时确认率约为69.73%/60.44%，原生效用约为0.24416/0.17814；M能耗更高。新基线尚无该同协议正式结果，不能声称已经优于贪心、匈牙利算法或标准PPO。仓库内历史同名算法如有其他结果，须先审查合同，不能直接并表。

在线移除世界模型的 N 保留既有训练权重，只是推理干预，不是标准PPO，也不是从未使用世界模型训练的GPPO。历史A成本失败和简化成本门未通过事实继续保留，不能用其他计时范围覆盖。

## 3. 公平性合同

- 原生M10合同与后来的有限通信扩展分开。第一组可比研究以已核验阶段2原生合同为依据；运行前绑定源码、checkpoint、配置、观测和动作编码完整哈希。
- 所有方法只接收同一公开信息白名单、公开历史、自身命令和真实收到的ACK；使用相同mask及共同ACK/未确认命令过滤。规划模型不能制造权限、读取未来任务/故障、访问环境私有对象或克隆真实环境搜索。
- 原生每秒最多提出一个25-action动作，NOOP=24。所有方法共享提交、续租、消息和终止语义。估计可行不等于真实执行器接受，拒绝和失败完整计入结果。
- 场景按独立parent拆分训练、开发和最终评价；相同parent/repeat配对，随机身份机制相同但分叉后消息序列不强求相同。不得按模型输赢、候选数量或成功率选样本。
- 旧阶段2场景已被开发分析，不再称为新的盲测。复用旧M/R须逐项证明合同兼容并标作开发性补充；新的确认性结论需在执行前冻结独立parent清单。
- 学习方法预先冻结相同训练环境步上限、开发调参额度、训练种子清单和checkpoint选择规则；完整模型先前的world预训练及策略续训全部计入，不能只比较最后一段训练。相同环境步不代表相同计算成本，另报完整CPU/GPU、wall和更新数。
- 固定偏好主比较先对齐(0.8,0.2)。若完整模型接受过跨偏好训练，明确这一训练分布差异，并在归因比较中匹配；不能把差异全部归因世界模型。偏好响应能力须另设跨偏好评价，当前不宣称已验证。

## 4. 评价与采用门

保留原生标签：r_task=(新完成−新过期)/6，r_energy=−能耗增量/36；U=Σ0.99^t(0.4*r_task+0.2*r_energy)。物理按时、主机按时确认、过期、能耗、命令拒绝分别报告。priority并未直接加权进入该向量任务奖励；U不是货币利润。

在该单位下保留实际收益阈值δ=0.01，不能通过改奖励尺度让差值更好看。任务护栏沿用物理按时率及主机按时确认率不下降，同时报告区间；旧均值护栏不包装成非劣检验。

新增多基线不能直接复制单比较显著性结论：正式协议需预定主比较及多重比较处理。建议在开发集按冻结效用、任务护栏和成本规则选一个非学习参照，独立评价时锁定；其余比较全部报告，不事后只挑模型胜出的对手。训练seed与parent不确定性分开报告。

同时报告完整控制器平均CPU、wall p95、RSS，训练/调参/加载/启动/执行总成本及规划展开或求解次数。沿用10ms平均CPU、50ms wall p95、4GiB RSS作为当前研究研发标准；10ms不是已证明不可突破的现场SLA。任何历史成本失败保留原协议结论，后续新标准只能单独登记，不能回改为通过。

达到效用、任务护栏与成本门才支持“相对此参照有实用增量”。动作变化、预测准确、实现完成、单次成功和参数量都不能代替任务收益。完整模型赢传统方法仍不等于world或偏好模块的独立贡献已证实。
