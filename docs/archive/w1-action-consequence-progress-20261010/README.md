## 监督审计与待验证假设

58 个训练机会窗口、24 个父场景中有 257 个合法候选。逐候选配对身份、轨迹和生命周期/效用标签复算通过，未发现这批数据的标签缺失或配对错误。NOOP 的目标任务标签为 unknown；其全局增量及其他任务标签仍可有效。

训练有 25 个全局增量 <= -0.1 的候选，来自 17 个窗口/14 个父场景，均存在同窗更好动作的排序监督。特定“目标任务获益且其他任务过期”只有 3 候选/3 窗口/3 父场景，覆盖稀少。

原排序损失按 batch 内全部有效不等候选对平均；单窗口 1–36 对，窗口权重不均。没有逐头训练 loss/梯度证据，不能把权重认定为错误根因。建议预注册单变量消融：窗口内先对有效排序对求均值，再对有效窗口求均值，保持其余训练设置不变。该消融尚无执行结果，本归档不授权新计算。

本次已查看的评价父场景已转为开发材料；未来确认须使用未查看场景。碰撞标签因模拟器未实现而保持 unknown，合法差结果仍保留。结果仅限开发探索，不认证 5% 风险，不作部署结论。

## 会议路线与当前边界

会议提出的动作后果预测、反事实监督与多头损失已经实现并完成本轮预测评价。旧固定 logits 先验与 actor 特征融合曾完成任务级实验但未建立实用收益；这不是新 critic-first 分支的任务结果。不能说会议路线全部验证失败，也不能说当前主线成功。
