日期：2026-09-23。状态：执行包准备；动态运行未授权。整体目标是找到值得保留的系统，不要求结果为正，不为GPPO/world名称保留组件。

## 唯一核心问题

在同一历史原生M10 25-action、当前公开信息与ACK-known guard下，冻结GPPO＋world组合能否胜过公开信息确定性规则，且增量是否足以值得研究其额外复杂度？本比较是组合价值，不能分解GPPO和world各自贡献。

复用H005/H006通过的恢复、奖励、预算、公开动作与分析合同。前轮normal/off效用相同，不能当模型不需要或规则已经获胜。R/K、heartbeat扫描、同配方触发路线保持封存。

## 规则冻结

`public-priority-edf-nearest-v1`：在原mask允许的分配动作中，依次按任务priority降序、deadline升序、公开二维Euclidean距离升序、UAV公开energy降序、action id升序排序。所有字段只从当前obs whitelist读取；输入非finite或合法动作字段不完整报技术错误，不读真值补齐。

同一原guard负责排除公开continuation身份指向的任务；不增加未公开assignment或lease判断。不删合法NOOP、不修改mask；NOOP保留在原候选中，规则把它排在有效分配后，所有分配被mask或guard排除时选择NOOP。这是公开服务规则的预定义动作偏好，不是改动作合同。

给guard的rank weights只承载确定性次序，不是概率校准预测。规则不使用world输出、policy/world hidden、训练权重或历史分支结果。prefix中继承的hidden若为公共恢复框架保留，仅作惰性审计数据，不传入scorer；原生环境/ACK/lease继续推进。完整模型臂保持真实selected by_action和policy hidden推进。

优先级、EDF、最近UAV是任务调度的合理简单基线；本轮没有在数据上扫描权重、挑规则或以收益调参。它不是所有可能启发式的最优者。规则未做速度/能耗预测，不假设控制端获得隐藏执行状态。
