# 历史证据索引与当前可回答问题（2026-09-11）

## 9.2 最新弱通信结论

| 变体 | 完成 |
|---|---:|
| GPPO | 84/288 |
| GPPO＋世界模型 | 82/288 |
| GPPO＋世界模型＋事件触发 | 49/288 |

GPPO＋世界模型未建立改善证据；事件触发减少 actor 调用但损害任务效果。历史 replay 的本机 CPU 完整链路均值为 A/B/C=1.8967/2.3177/2.1217 ms，C 对 B 约低 8.5%，对 A 约高 11.9%；这些只适用于本机 CPU、2 线程、无预热、不含落盘，不外推 GPU 或实时性。

## R3 预测质量边界

旧 R3 final-test 的固定世界模型 event PR-AUC 为 damage/disconnect/reconnect=0.077/0.134/0.061，0.5 阈值 precision/recall 均为 0；event BCE 0.258 高于训练阳性率基线 0.166，done BCE 0.266 高于训练阳性率基线 0.221。Graph-5 World return 32.156±2.179，未超过 MLP-2 32.445±1.785 或 Graph-2 32.424±1.777。上述结果是旧 R3 版本证据，不是 9.11 新实验。

旧 R3 learning-budget ladder 的 validation return 也仍在旧版本证据中：Graph-5 Base 为 30.963→29.251，Graph-5 History 为 25.756→35.421，Graph-5 World 为 25.641→37.128（2048→8192 环境步）。这说明 2048 步不能称学习充分，但不证明 8192 步已收敛；9.11 不把该曲线重命名为新实验曲线。

## 传统方法回答边界

GPPO-8.29-baseline 的历史报告显示，在其随机事件合同和样本上，Greedy Cost/Nearest Legal/Min Load 等传统方法曾高于当时 GPPO；其中 Greedy Cost 约为 127.032 return。该合同、奖励、事件带和版本不同，不能回答“传统方法在最新弱通信合同下表现怎样”。9.11 必须在同一新合同下重新运行合法传统调度器，才能给出直接比较。

## 当前三问

- 传统方法表现怎样：最新弱通信合同下尚无统一实测；旧合同的正向历史仅作动机。
- 历史信息是否足够：旧 Graph-5 History 与 World 的差异未形成稳定收益证据，不能称“足够”；需要同预算历史信息对照。
- 世界模型是否提供额外价值、收益是否值得成本：当前没有证据。新设计以候选后果预测、独立预测质量和总计算成本作为可证伪检验，不预先承诺改善。
