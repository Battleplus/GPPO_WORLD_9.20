# 从最终结果倒推的五阶段研究路线

更新：2026-09-25（当前位置与基线准备）；五阶段目标保留。本路线替代早期“先修通信合同”的阶段安排；历史版本见 [旧路线](history/20260920/ROADMAP.md)。历史实验编号保持原名，不按本路线重新编号。

## 最终成果

在有限通信、任务到达和执行中断条件下，建立能根据偏好进行任务—能耗决策的系统：相对合理公开信息基线有可重复的实际增量，组件贡献可分辨，计算与通信成本可测，结论能在独立场景中成立。

研究方向保留 GPPO＋世界模型＋事件预测/触发＋偏好学习。是否保留每个组件由证据决定；不能以“必须四个模块齐全”代替研究成功，也不能因当前方案不通过就宣称整个方向无效。

## 五个阶段

| 阶段 | 需要得到的结果 | 通过条件与后续 |
|---|---|---|
| 1. 证明问题值得学习 | 有真实且可重复的决策取舍；决策前可获得的信息有助于区分选择；简单规则有明确不足 | 固定一个有实际意义、可检验的学习问题。若没有，暂停当前模型方案或重新论证问题，不靠挑选失败样本制造机会 |
| 2. 证明学习系统有增量 | GPPO＋世界模型在独立开发父场景中优于合理规则，且收益达到预先规定的实用阈值 | 才值得投入组件研究。负结果或不确定结果保留，不自动补样、调参或更改指标 |
| 3. 证明各组件的价值 | 区分 GPPO、世界模型、公开历史各自贡献；识别可删除的复杂部分 | 冻结必要结构。整体模型胜出不等于世界模型有独立贡献 |
| 4. 实现偏好与事件自适应 | 改变偏好能稳定改变真实任务—能耗取舍；事件触发在保留任务性能时减少实际成本 | 分别验证偏好响应与触发成本，不用 actor 调用减少代替完整成本下降 |
| 5. 证明可靠与可推广 | 在独立父场景、多模型 seed、不同通信及故障条件下，收益、成本与执行合同结论仍成立 | 才形成研究总体结论。仿真结论不自动升级为生产部署验收 |

## 统一决策纪律

- 验收依据是结果及其解释边界，不是测试通过、文件齐全或代码能运行。
- 独立性以父场景为基础；同一父场景的前缀、重复和模型 seed 不冒充独立外生样本。最后一阶段的盲测集不能提前用于开发选择。
- 合理基线应能利用同样合法的公开信息和历史；模型多用了历史，不可直接归因为 world 的价值。
- 开发场景须先说明实际应用依据、生成规则和覆盖范围，不能按模型输赢筛选。
- 每次新正式实验先冻结问题、对照、划分、指标、资源预算与停止条件；本路线不自动授权训练、正式采样或读取盲测结果。
- 已有 δ=0.01 只属于原冻结效用合同；新合同阈值须事先论证，不能在看结果后调低。
- 整体目标允许更简单的结构，但必须如实区分路线暂停、方案封存、收益不确定与总体目标完成。
