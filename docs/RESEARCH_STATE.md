# 研究状态与决策依据

## 总目标

有限通信、延迟、丢包及断联下，无人机按时完成普通任务，响应新到达紧急任务，恢复中断任务，并在任务效果、能量和通信成本间产生可解释的偏好权衡。

技术路线保留GPPO、动作条件世界模型、事件预测与触发、偏好学习。当前先收口环境通信合同，再研究缺失观测下的估计和决策价值。

区分：本地周期计算、周期上报、主动查询。当前没有主动查询机制；新紧急任务由external_task_publisher在实际到达后公告，这是仿真假设。
